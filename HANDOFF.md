# Handoff — club.kawaii (2026-11-02)

## Контекст
**club.kawaii.uz** — платформа авторов по типу Patreon + Boosty: клубы с подписками, закрытые посты, лента, эфиры.
Часть семейства kawaii (`kawaii.uz`, `tv.kawaii.uz`, `radio.kawaii.uz`, `bot.kawaii.uz`). Общие компоненты взяты из репозитория kawaii_TV.

### Дизайн
- Один стиль с остальными сайтами: TopBar, Plus Jakarta Sans + DM Mono, `bg-card-bg`, фиолетовый `primary`, светлая и тёмная темы.
- **Характер сайта — клубные карты.** Тариф = коллекционная карта в цвете автора с голографическим слоем, она наклоняется за курсором. После оплаты карта «выпускается» с номером участника.
- Мобилка как приложение: чёрный фон, нижняя навигация, меню справа, панели снизу со свайпом. На ПК — модальные окна по центру с крестиком.

## Маршруты (`src/app/(app)/`)
| URL | Что там |
|---|---|
| `/` | Приветственный блок в стиле «выбора персонажа»: на весь экран арт и цвет выбранного автора, за картами крупно его имя, колода карт (на телефоне свайп), внизу лента аватаров с прогрессом автопереключения. Ниже эфиры и популярные клубы |
| `/feed` | Лента. «Hammasi» — посты всех авторов, как в Patreon, через каждые 3 поста карточка нового автора. «Obunalarim» — только подписки. Новичок видит «Hammasi»; после первой подписки лента открывается на «Obunalarim»; выбранная вкладка запоминается. На ПК три колонки |
| `/creators` | Каталог авторов: поиск, категории (`?c=`), сортировка |
| `/live` | Эфиры сейчас и запланированные |
| `/wallet` | Кошелёк клубных карт (стопкой), детали подписки, смена тарифа, отмена |
| `/[creator]` | Страница автора: баннер, карты-тарифы (на ПК справа, на мобилке карусель), вкладки Посты / Медиа / О клубе |
| `/[creator]/live` | Эфир: плеер с danmaku, чат, донаты, закрытые эфиры для тарифа |

## Ключевые файлы
- `lib/club.ts` — данные-заглушки: авторы, тарифы, посты, форматтеры.
- `lib/membership.ts` — подписки пользователя (localStorage, `useSyncExternalStore`), правила доступа `canSee` и `hasTier`.
- `components/club/ClubCard.tsx` — клубная карта и `useTilt`. Стили в `app/club.css`.
- `components/club/JoinSheet.tsx` — оформление подписки: тариф, срок, способ оплаты, выпуск карты. Открывается из любого места через `openJoin(creatorId, tierId?)`.
- `components/club/ClubHero.tsx`, `PostCard.tsx`, `CreatorView.tsx`, `Tiles.tsx`, `stream/StreamView.tsx`.

## Что заглушено
- Оплата (Click / Payme / Uzum / карта) — имитация, реальной оплаты нет.
- Чат эфира и зрители — генерируются на клиенте. Видео эфира — тестовый файл `public/media/stream.mp4`.
- Аккаунты — нет, подписки и выбранная вкладка ленты хранятся в браузере (`club.memberships`, `club.feedTab`). У нового посетителя подписок нет.
