# Handoff — club.kawaii (2026-11-02)

## Контекст
**club.kawaii.uz** — платформа авторов по типу Patreon + Boosty: клубы с подписками, закрытые посты, лента, эфиры.
Часть семейства kawaii (`kawaii.uz`, `tv.kawaii.uz`, `radio.kawaii.uz`, `bot.kawaii.uz`). Общие компоненты взяты из репозитория kawaii_TV.

### Дизайн
- Один стиль с остальными сайтами: TopBar, Plus Jakarta Sans + DM Mono, `bg-card-bg`, фиолетовый `primary`, светлая и тёмная темы.
- **Характер сайта — клубные карты.** Тариф = коллекционная карта в цвете автора с голографическим слоем, она наклоняется за курсором. После оплаты карта «выпускается» с номером участника.
- Мобилка как приложение: чёрный фон, нижняя навигация, меню справа, панели снизу со свайпом. На ПК — модальные окна по центру с крестиком.

## Ключевые файлы
- `lib/club.ts` — данные-заглушки и типы: авторы, тарифы, посты, эфиры (`StreamAccess`, `record`, `chat`), товары, комментарии.
- `lib/store.ts` — `createStore` (localStorage + useSyncExternalStore), `createOpener` для глобальных окон, `useNow`.
- `lib/account.ts` — аккаунт (вход через Telegram — заглушка), платежи, покупки, подарки, активность, уведомления.
- `lib/membership.ts` — подписки, пробный период, стаж карты (3 мес — бронза, 6 — голограмма, 12 — золото).
- `lib/studio.ts` — клуб автора, его посты и эфир; общие хуки `useCreators` / `usePosts`; правила доступа `canSeePost` / `streamAccess`.
- `lib/shareCard.ts` — рисует карту в PNG 1080×1350.
- Окна: `JoinSheet` (себе / в подарок, пробный период), `sheets.tsx` (вход, оплата), `DonateSheet`, `NotificationsSheet`, `media.tsx` (просмотр фото, видео, аудио).

## Что заглушено
- Оплата, вход через Telegram, вывод денег — имитация. Реальных денег и данных нет.
- Все данные пользователя и автора хранятся в браузере (`club.*` в localStorage).
- Чат эфира и клуба частично генерируется. Видео и аудио — один тестовый файл `public/media/stream.mp4`.
